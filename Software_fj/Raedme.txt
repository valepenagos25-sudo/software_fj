# Sistema Integral Software FJ

Proyecto desarrollado en Python orientado a objetos para la gestión de clientes, servicios y reservas.

Características:
- Programación orientada a objetos
- Abstracción
- Herencia
- Polimorfismo
- Encapsulación
- Manejo avanzado de excepciones
- Registro de logs
- Simulación de reservas

Servicios:
- Reserva de salas
- Alquiler de equipos
- Asesorías especializadas
